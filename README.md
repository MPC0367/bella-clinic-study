# Bella Clinic — design preview

A design preview of a new website for Bella Clinic (Sukhumvit 33/1, Bangkok), made by
[O2 Design Studio](https://o2-designstudio.com/).

**View it:** https://mpc0367.github.io/bella-clinic-study/

## What this is

- A **preview, not Bella Clinic's live website.** Every page says so in a bar at the top.
- Captured pages of the public site, the online-booking flow and the member area, in Thai,
  English and Simplified Chinese.
- **Nothing here books, calls, messages or signs in to anything.** Phone, LINE and booking buttons
  show a short note instead of acting; the booking steps and the member logins are demonstrations
  with sample data. The sample members are invented.
- Prices, offers, policies and articles are sample content for the clinic to review, not final.
- Not listed on search engines (`noindex`).

The site is served from the `gh-pages` branch. This branch holds only this note and `NOTICE.md`;
the application's source code is kept privately by the studio.
